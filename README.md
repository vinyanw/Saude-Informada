# Saude-Informada
Saúde Informada é um projeto de pesquisa de desenvolvimento tecnológico proposto ao PIBIT do Instituto Federal do Maranhão (IFMA). A proposta tem como objetivo apontar melhorias no sistema do Meu SUS Digital. Além de apontar melhorias estruturais no município de Caxias (MA) com o uso de algoritmos em grafos. 

O projeto está desenvolvido em três etapas através do material "Basic Guidelines for Research: An Introductory Approach for All Disciplines" de Syed Muhammad Sajjad Kabir (2016): 
- Fase de planejamento
- Fase de projeto
- Fase de documentação

Tecnologias usadas serão a prototipagem de design através do Figma, para construir protótipos de produtos bastante utilizada na área de User Experience (UX).
